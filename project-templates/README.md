# Public Demo Templates

These templates are safe starting points for public GitHub projects. They do not include proprietary datasets, private model weights, or client code.

Recommended public demos to create:

1. **Generic Video Counter**
   - Uses a public video or synthetic example.
   - Demonstrates line-crossing logic, reporting, and clean overlays.

2. **DINO/FAISS Image Retrieval Demo**
   - Uses a public image dataset.
   - Demonstrates embedding extraction, FAISS indexing, top-k retrieval, and evaluation.

3. **OpenCV Reference-vs-Test Difference Demo**
   - Uses synthetic or public PCB-like images.
   - Demonstrates alignment, SSIM, masks, and anomaly crops.

The goal is not to reveal the real client work. The goal is to prove the underlying technical ability on safe examples.
