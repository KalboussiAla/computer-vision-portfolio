# Research Direction

My strongest direction is **industrial visual intelligence**: computer vision systems that combine robust models, high-quality datasets, reliable evaluation, and deployable software.

## Core Research Axis

**Data-centric computer vision for deployable industrial AI systems**

This axis connects my applied work:

- object detection and counting;
- fine-grained recognition;
- visual retrieval;
- anomaly detection;
- annotation systems;
- active learning and semi-annotation;
- deployment and operational reporting.

## Why This Direction

In real projects, the hard part is rarely "train a model once." The hard part is:

- choosing what to annotate next;
- detecting label mistakes;
- handling domain shift;
- measuring the right metric;
- turning model outputs into decisions;
- keeping the system reliable on imperfect images and videos.

## Research Questions I Want to Explore

1. How can active learning reduce annotation cost in industrial object detection?
2. How can foundation model embeddings improve fine-grained recognition under domain shift?
3. How can retrieval and classification be combined for large visual product catalogs?
4. How can visual inspection systems work with few or no defect examples?
5. How can annotation platforms become part of the model improvement loop?
6. How can AI agents and LLM-based tools automate parts of dataset analysis, experiment review, and deployment reporting?

## Long-Term Goal

My long-term goal is to build research-driven AI systems that become real products: tools that help factories, retailers, labs, and smart infrastructure use visual intelligence reliably.
