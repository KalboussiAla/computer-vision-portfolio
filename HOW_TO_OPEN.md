# How to Open This Portfolio

There are two ways to view this portfolio.

## 1. GitHub Repository

Open:

https://github.com/KalboussiAla/computer-vision-portfolio

This is the repository view. It shows the README, case studies, project index, and technical documents.

Use this link in:

- CV;
- LinkedIn;
- emails to professors;
- applications.

## 2. Portfolio Website

Open:

https://kalboussiala.github.io/computer-vision-portfolio/

This is the website view generated by GitHub Pages from `index.html`.

## Why There Is an HTML File

`index.html` is the homepage used by GitHub Pages. It makes the portfolio look like a small website instead of only a list of Markdown files.

The GitHub repository is for technical reading.  
The GitHub Pages website is for a quick first impression.
