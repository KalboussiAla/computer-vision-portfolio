PFE: Industrial Object Counting

A confidential industrial computer vision project focused on counting dense repeated objects from real operational images. The public version keeps the technical value and metrics while removing internal dataset names, diagrams, client identifiers, and implementation-sensitive details.

64%initial reproduced baseline
91.8%final image-level counting accuracy
98.9%precision on evaluated images
98.1%recall on evaluated images
0.6mean absolute error per image
230curated images beat a larger noisy dataset
Baseline reproduction

Rebuilt the initial detector, verified the evaluation protocol, and established a trusted starting point before claiming improvement.

Data and label engineering

Audited labels, corrected inconsistent annotations, selected difficult examples, and tested alternative annotation strategies.

Preprocessing experiments

Explored edge-oriented preprocessing, contour extraction, contrast and structure filters, and image-size changes to study what helped the detector.

Advanced prototypes

Explored segmentation, dense-object strategies, controlled difficult-case training, model combination, and high-level routing ideas without exposing internal logic.

Online testing backend

Built a backend environment to test models through realistic inference flows instead of relying only on local notebooks.

Deployment-ready result

Selected a final model based on accuracy, stability, speed, memory constraints, maintainability, and inventory-oriented reuse.

Internal Annotation and Dataset Platform

Alongside the model work, I built a platform-oriented workflow for annotation, correction, filtering, export, and dataset iteration. The public version describes the architecture and role without using the internal product name.

What it enabled

  • Image import with or without labels.
  • Manual annotation and assisted correction.
  • Conversion of predictions into editable annotations.
  • Filtering and dataset preparation for training.
  • Export into standard computer vision formats.

Architecture

Frontend annotation interface, backend services, typed RPC communication, metadata storage, object storage, and training/export workflows.
